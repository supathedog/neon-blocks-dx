# NEON BLOCKS DX

このリポジトリは「NEON BLOCKS DX」というテトリス風ゲームのためのリポジトリです。

注意: リポジトリにゲームの実際のソースコードは含まれていません。
このリポジトリには現時点でプレースホルダの `index.html` を配置しています。ゲーム本体（JavaScript/CSS/アセット）をアップロードすると、GitHub Pages 経由でブラウザ上で公開できます。

使い方（ファイルを追加する手順）

1. ゲームのファイル一式（index.html, js/, css/, assets/ など）を用意する。
2. リポジトリのルートにアップロードする（例: `index.html` を置く）。
3. main ブランチのルートに `index.html` があれば、gh-pages ブランチを作成して同じファイルを配置するか、リポジトリ設定で GitHub Pages を `main` ブランチのルートに設定してください。
4. 公開 URL: https://supathedog.github.io/neon-blocks-dx/

もしゲームのソースコードをこちらに送っていただければ、私のほうで index.html とアセットを配置して公開まで行います。
